## 👋 Sobre

Portfólio voltado à **aplicação prática de tecnologias** para análise de dados, modelagem preditiva, processamento
de grandes volumes de informação e automação de processos.

```mermaid
flowchart LR
    A["📡 Coleta<br/>sensores e MQTT"] --> B["📨 Mensageria<br/>Apache Kafka"]
    B --> C["🗄️ Armazenamento<br/>MongoDB · SQLite · Parquet"]
    C --> D["⚙️ Processamento<br/>ETL · Airflow · DuckDB"]
    D --> E["🤖 Modelagem<br/>Random Forest · TF-IDF"]
    E --> F["📊 Visualização<br/>Power BI · Streamlit · dashboards"]

    A -.- P1(["Smart City Data Platform"])
    B -.- P2(["Data Analytics"])
    E -.- P3(["SmartPredict"])
    F -.- P4(["Sistema de Calibração"])
```

<sub>Do dado bruto à decisão: cada etapa aparece em pelo menos um dos projetos abaixo.</sub>
